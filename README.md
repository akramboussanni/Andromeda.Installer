# Andromeda.Installer

Andromeda.Installer is the player-friendly setup path for **Enemy On Board** with Andromeda. Forked from MelonLoader<s installer

Releases include Windows x64, Linux x64, and a universal macOS app for both Intel and Apple Silicon. On Mac, download `Andromeda.Installer.MacOS.dmg`, open it, and drag **Andromeda Installer** to **Applications**. Eject the disk image and open the installer from Applications. The app and disk image are Developer ID signed and notarized by Apple. The ZIP asset is retained for automatic updates.

## What It Does

- Installs MelonLoader.
- Installs Andromeda into the game `Mods` folder.
- Applies loader configs.
- Pulls the latest `Andromeda.Mod` release automatically.
